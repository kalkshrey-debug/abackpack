<h2>✨ Why ABackPack?</h2>

<table>
  <tr>
    <td width="50%">
      <h3>🔒 100% Offline & Zero Cloud</h3>
      <p>Your files travel strictly through your USB data cable or local Wi-Fi/Hotspot (<code>192.168.x.x</code>). Nothing is ever uploaded to any external server.</p>
    </td>
    <td width="50%">
      <h3>💎 0% Quality Loss</h3>
      <p>Raw byte-for-byte streaming preserves original photo/video resolution, audio bitrate, EXIF metadata, and gallery thumbnails.</p>
    </td>
  </tr>
  <tr>
    <td width="50%">
      <h3>🛡️ No Login & No History</h3>
      <p>No accounts to create, no logs stored, and zero risk of cloud data leaks or server hacks.</p>
    </td>
    <td width="50%">
      <h3>🔍 Code Transparency</h3>
      <p>The entire source code is public so you can inspect every single line anytime to verify how it works.</p>
    </td>
  </tr>
</table>

<h2>🚀 Quick Setup & Usage</h2>

<ol>
  <li>Download the latest <strong><code>ABackPack_v1.0.zip</code></strong> from the <strong>Releases</strong> section.</li>
  <li>Extract the ZIP directly into your <strong><code>C:\</code></strong> drive so the folder path becomes <strong><code>C:\ABackPack\</code></strong>.</li>
  <li>Double-click <strong><code>abackpack.exe</code></strong> (or run <code>python main.py</code> from source).</li>
  <li>Select <strong>Wired Connection</strong> or <strong>QR Code</strong> and follow the on-screen instructions.</li>
  <li>All backups are saved safely inside <strong><code>C:\ABackPack\Backups\</code></strong>.</li>
</ol>
